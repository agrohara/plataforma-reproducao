# Skills selecionadas: apps e Power BI

Curadoria de 19 skills tiradas de 4 repositórios (claude-skills, frontend-agent-skills, agent-skills, awesome-design-skills). Cada pasta é uma skill completa (SKILL.md + referências), sem alteração no conteúdo original. Licenças MIT na pasta `LICENSES/`.

## 1. Fundamentos de UI/UX (apps e Power BI)

| Skill | Para que usar |
|---|---|
| `refactoring-ui` | Hierarquia visual, cor, espaçamento. Traz `references/data-visualization.md` (escolha de gráfico, tabelas, layout de dashboard). **A mais útil para Power BI.** |
| `ui-visual-composition` | Composição, grid, tipografia, cor e estados visuais; checklists de revisão. |
| `information-architecture-navigation` | Organização de páginas, menus, rótulos e caminhos de navegação (navegação entre páginas de relatório, drill-through). |
| `interaction-patterns-components` | Qual componente usar (filtros, abas, tabelas, modais, cards) em apps e dashboards. |
| `ux-usability-foundations` | Feedback, restrições, prevenção de erro, clareza do fluxo. |
| `ux-writing-content-design` | Títulos de visual, rótulos, tooltips, mensagens de erro e estados vazios. |

## 2. Desenvolvimento de aplicativos

| Skill | Para que usar |
|---|---|
| `ui-ux-design` | Gerar interface pronta em código com todos os estados (hover, foco, loading, erro). |
| `design-systems-frontend-architecture` | Design tokens, componentes reutilizáveis, CSS, layout responsivo. |
| `forms-inputs-checkout` | Formulários, validação e telas de entrada de dados. |
| `clean-code` | Nomes, funções pequenas e tratamento de erro no código do app. |

## 3. Storytelling com dados

| Skill | Para que usar |
|---|---|
| `made-to-stick` | Checklist SUCCESs para tornar a mensagem de um relatório executivo clara e memorável (manchete do dashboard, narrativa da apresentação). |

## 4. Presets visuais (estilos prontos, ~5 KB cada)

Use um por projeto como ponto de partida de paleta, tipografia e espaçamento.

| Preset | Perfil |
|---|---|
| `ant` | Enterprise, denso em dados (bom para relatórios analíticos). |
| `enterprise` | Dashboard escuro, painéis modulares. |
| `stitch` | Enterprise de alto contraste para fluxos orientados a dados. |
| `corporate` | Corporativo, grid estruturado, minimalista. |
| `bento` | Grade de cards (bom para página executiva de KPIs). |
| `clean` | Muito espaço em branco, paleta limitada. |
| `shadcn` | Componentes monocromáticos e limpos (apps web/React). |
| `material` | Material Design (apps multiplataforma). |

> Lembre de trocar as cores do preset pela paleta da Agro Hara quando o material for institucional.
